treekv: a tree-structured KV cache in llama.cpp

Markdown + LaTeX · Llama-3.2-1B-Instruct Q4_K_M · llama.cpp 10a60cf, CPU only · Pinaksh, Reehan, Ishaan

Domain and method

  • Markdown: 5 llama.cpp docs; units = sections by heading level.
  • LaTeX: TeX Live sample2e + 4 math notes; units = sections, theorem/lemma/definition/proof/figure/table environments (pylatexenc). A proof becomes the child of the statement it proves.
  • One sequence ID per leaf; every ancestor carries all its leaves' IDs, so llama.cpp's mask = the tree mask.
  • Children start right after their parent: siblings share positions, every root-to-leaf path is gap-free.
  • Subtrees under 32 tokens are merged (at most 254 leaves, keeping 2 sequences for the question and the layout check).
  • Evict = seq_rm(seq, p0, p1) for the subtree's own sequence IDs.
